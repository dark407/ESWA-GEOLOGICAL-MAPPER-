1. EXECUTIVE SUMMARY & MISSION
================================================================================
AKASH TUNNEL MAPPER is an industrial geotechnical and underground tunnel mapping
software suite developed for mining, hydro-tunnel, metro, and civil construction
projects. It runs across Web, Windows Desktop (.EXE / .BAT), and Android (.APK).

Key capabilities:
- Photogrammetry & Surface Joint Tracing: Extracts geological fractures from photos
  using a hybrid Computer Vision (CLAHE, Sobel, Ridge Skeleton) + Gemini AI pipeline.
- 3D Structural Orientation: Converts 2D curved photo traces into True Strike,
  Dip Angle, and Dip Direction (000°-360°) by 3D projection onto tunnel geometry.
- Stereonet Analysis: Fisher pole clustering into joint sets (Set 1, Set 2, Set 3,
  Random) on Schmidt (Equal-Area) and Wulff (Equal-Angle) stereonets.
- Geotechnical Classification: Automatic evaluation of Barton's Q-System,
  Bieniawski's RMR (1989), Hoek-Brown GSI, and Romana's SMR.
- Kinematic Failure & Support Design: Calculates Factor of Safety (FoS) for roof
  and sidewall wedges, planar sliding, toppling, and spot bolting schedules.
- Overbreak & Undercut Analysis: Integrates surveyed profiles against design CAD
  sections to calculate volume differences (m³/m) and diagnose root causes
  (geological fallout vs. mechanical drill-and-blast deviation).
- Continuous As-Built Tunnel Logging: Flat unwrapped logging strip
  (Left Wall -> Crown -> Right Wall) with chainage schedules, lithology contacts,
  joint intersections, and Bill of Quantities (BoQ).
- Diamond Drill Core Logging: Geotechnical borehole workspace tracking TCR, SCR,
  RQD, fracture frequency (FF/m), and weathering indices.
- 1-PC Hardware Locked Licensing: Anti-piracy device binding tied to hardware
  hashes, managed via a Master Admin Portal and Firebase Firestore.

3. COORDINATE SYSTEMS & GEOMECHANICAL MATHEMATICS
================================================================================
3.1 Photo Space vs. Tunnel Space:
- Normalized Photo Coordinates (u, v):
  u in [0.0, 1.0]: Horizontal axis (u=0: left edge, u=1: right edge).
  v in [0.0, 1.0]: Vertical axis (v=0: top/crown, v=1: invert/floor).
- Local 3D Tunnel Coordinates (X, Y, Z):
  X: Lateral position across tunnel width (m).
  Y: Vertical height above invert level (m).
  Z: Longitudinal alignment chainage (m), e.g., CH 12+450.50.
- Drive Direction Azimuth (alpha_drive):
  Measured clockwise from True North (000°-360°).
  Surface normal transformations:
  * Tunnel Face: Opposite to drive direction (alpha_drive +/- 180°).
  * Left Wall: Oriented at (alpha_drive - 90°).
  * Right Wall: Oriented at (alpha_drive + 90°).
  * Crown: Vertical normal (+Y).

3.2 3D Orientation Calculation:
- Traced polylines P1(u,v) ... Pn(u,v) are back-projected onto the 3D surface mesh.
- A 3D best-fit plane Ax + By + Cz + D = 0 is computed using SVD / Least-Squares.
- Dip Angle (beta): beta = arccos(|C| / sqrt(A² + B² + C²)).
- Dip Direction (theta_dip): Derived from the horizontal gradient vector.
- Strike (theta_strike): theta_strike = (theta_dip - 90°) mod 360° (Right-Hand Rule).

3.3 Stereonet Pole Projection:
- Schmidt (Equal-Area): Radius R = sqrt(2) * sin((90° - beta) / 2).
- Wulff (Equal-Angle): Radius R = tan((90° - beta) / 2).
- Joint sets grouped via Fisher clustering with concentration parameter (K).

3.4 Barton's Q-System Formulation:
  Q = (RQD / Jn) * (Jr / Ja) * (Jw / SRF)
  * Block size parameter: (RQD / Jn)
  * Inter-block shear strength: (Jr / Ja)
  * Active stress state: (Jw / SRF)
  Equivalent excavation dimension: De = Span / ESR.
  Grimstad & Barton (1993) permanent support recommendation curve calculation.

3.5 Bieniawski's Rock Mass Rating (RMR 1989):
  RMR89 = R1(UCS) + R2(RQD) + R3(Spacing) + R4(Condition) + R5(Groundwater) + R6(Orientation Adjustment)
  Classifies rock mass:
  * Class I: Very Good Rock (81 - 100)
  * Class II: Good Rock (61 - 80)
  * Class III: Fair Rock (41 - 60)
  * Class IV: Poor Rock (21 - 40)
  * Class V: Very Poor Rock (< 21)

3.6 Overbreak Radial Integration:
  V_overbreak = 0.5 * integral[0 to 2pi] (r_actual² - r_design²) dTheta * L_round (m³)
  Partitioned into:
  - Geological Overbreak (unfavorable joint daylighting / wedge fallout).
  - Mechanical Overbreak (over-drilling, blast charge excess, burden variance).

5. CORE ENGINES DEEP DIVE (src/engine/*)
================================================================================
5.1 cvPipeline.ts & cameraCalibration.ts:
- Runs local computer vision directly on the canvas image:
  * Grayscale conversion.
  * Contrast Limited Adaptive Histogram Equalization (CLAHE) with tile grid size 8x8.
  * Sobel horizontal and vertical edge filters to find gradient magnitude and direction.
  * Dark-Valley ridge extraction linking local intensity minima into multi-point polylines.
  * Filters out high-frequency noise from rock dust or lighting glare.
- Camera calibration handles lens barrel/pincushion distortion correction (k1, k2, p1, p2)
  and calculates stereo baseline distance between multiple camera shots.

5.2 geometryEngine.ts & customProfileEngine.ts:
- Parameterizes standard cross-sections:
  * D-Shaped Tunnel (vertical sidewalls + semicircular crown arch).
  * Horseshoe Tunnel (curved sidewalls with springline fillet radii).
  * Circular Tunnel (bored TBM profile with invert fill).
  * Basket-Handle / Multi-Centered Arch.
- Handles top heading vs. benching division:
  Splits full profile into Top Heading (excavated first) and Bench/Invert (excavated later)
  with independent face mapping surfaces and chainage tracking.
- customProfileEngine.ts supports freeform parametric polylines, B-spline curves,
  survey control point anchoring, and AutoCAD DXF profile import.

5.3 orientationEngine.ts:
- Converts 2D polyline vertices (u, v) into 3D world coordinates (X, Y, Z).
- Fits an orientation plane using Least Squares / SVD.
- Determines True Dip Angle and True Dip Direction relative to tunnel drive azimuth.
- Clusters discontinuity poles into Joint Sets using Fisher distribution algorithms.

5.4 overbreakEngine.ts:
- Samples actual surveyed profile perimeter at 360 angular increments (1° step).
- Calculates delta r(theta) = r_actual(theta) - r_design(theta).
- Positive delta r indicates Overbreak; negative delta r indicates Undercut.
- Calculates total overbreak volume (m³) and linear meter rate (m³/m).
- Evaluates geological structure influence vs. mechanical drill hole deviation.

5.5 rockMassClassificationEngine.ts:
- Calculates Barton Q index and recommended support class (1 through 9).
- Evaluates Bieniawski RMR89 with 6 rating parameters and strike/dip adjustments.
- Evaluates Geological Strength Index (GSI) via surface condition and block structure.
- Evaluates Romana Slope Mass Rating (SMR) for surface portal slopes.

5.6 continuous3DStripEngine.ts & projectNetworkStripEngine.ts:
- Unwraps 3D cylindrical tunnel into an A3 continuous strip:
  Left Wall (Top Panel) -> Crown (Middle Panel) -> Right Wall (Bottom Panel).
- Generates chainage ticks, geological contacts, fault zones, joint traces,
  water inflow symbols, and rock support Bill of Quantities (BoQ) schedules.
- Connects multi-round excavation pulls into a unified tunnel network.

5.7 softwareLicensingEngine.ts:
- Computes SHA-256 hardware identifier (pcHardwareId) from machine hardware properties.
- Checks hardware lock against Firestore /software_licenses/{userId}.
- Rejects unauthorized machines with hardware mismatch notice.
- Caches tamper-evident local activation token for offline field operation.

6. SERVER BACKEND & API MICROSERVICES (server.ts)
================================================================================
The Node.js Express server runs on port 3000 (0.0.0.0) with endpoints:

1. POST /api/ai/trace-joints:
   Receives base64 tunnel image, tunnel width/height, drive azimuth, and CV candidates.
   Calls Gemini 3.8 Flash to segment, classify, and verify geological discontinuities.
   Returns multi-point polylines with aperture, roughness, and water condition.
   Falls back seamlessly to local deterministic CV pipeline if API key is not present.

2. POST /api/ai/eswa-chat:
   ESWA AI Executive Assistant chatbot. Receives live application state snapshot
   (active geometry, joint count, overbreak volume, FoS, spot bolting data).
   Answers technical questions and executes application actions (e.g., opens panels,
   changes geometry, switches views).

3. POST /api/ai/analyze-geotech:
   Geotechnical engineering copilot. Diagnoses overbreak root causes (geological vs.
   mechanical), predicts next-round advance risk, calculates support FoS, and
   recommends exact spot bolting locations.

4. POST /api/geometry/parse-cad:
   Parses binary AutoCAD DWG or text DXF files. Scans IEEE-754 double coordinate pairs
   to reconstruct tunnel geometry cross-sections without external CAD licenses.

5. GET /api/offline-pc-installer:
   Builds a 100% self-contained offline Windows installer (.BAT / .HTML).
   Extracts bundled code to %LOCALAPPDATA%\AkashTunnelTracer and creates desktop
   shortcuts that launch in isolated app windows without requiring internet access.

6. GET /api/ota/latest-bundle:
   Delivers Over-The-Air update bundles (CSS + IIFE JS) to installed desktop and
   Android devices, preserving all existing local tunnel project databases.

7. POST /api/github/push-and-build-exe:
   Commits source code to GitHub and triggers GitHub Actions workflows to build
   official Windows Master .EXE, User .EXE, and Android .APK artifacts.

   - 0_TUNNEL_DESIGN (nominal design excavation line)

   High-resolution vector PDF export in standard A3 Landscape format.
